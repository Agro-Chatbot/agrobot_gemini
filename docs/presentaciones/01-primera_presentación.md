# Propuesta del proyecto

Cada grupo entrega un documento de 2 a 4 carillas, a elección: un press release o un PRD. En cualquiera de los dos formatos tiene que responder explícitamente:

1. Por qué el problema necesita un modelo de lenguaje y no se resuelve mejor con software convencional.
2. Con qué datos o corpus funciona y de dónde salen, ya explorados.
3. Cómo van a medir que funciona: métrica, alternativa contra la que comparan, hipótesis.
4. Cuál es el mayor riesgo técnico y cuál es el plan B.
5. Qué queda explícitamente afuera del alcance.
6. Cómo piensan estimar el costo de operar el sistema.
